# MathRenderAPI

MathRenderAPI is a RESTful web service that generates images for mathematical formulas, provided as URL-encoded ASCIIMath input and optional URL-encoded CSS for styling. It also offers a permalink feature, allowing formulas to be shared and referenced easily.

## Features
- Generate images from ASCIIMath-encoded formulas
- Customize formula appearance with CSS
- Create permalinks for any formula
- Generate images from previously created permalinks

## Endpoint

**Generate an image from ASCIIMath and CSS**

GET /api/render?formula={url_encoded_formula}&style={url_encoded_css}

Parameters:

- `formula`: URL-encoded ASCIIMath formula
- `style`: URL-encoded CSS to apply (optional)

Response: An image representing the provided formula

**Create a permalink**

GET /api/permalink?formula={url_encoded_formula}&style={url_encoded_css}

Parameters:

- `formula`: URL-encoded ASCIIMath formula
- `style`: URL-encoded CSS to apply (optional)

Response: A URL that can be used to regenerate the same image in the future

**Generate an image from a permalink**

GET /api/render?permalink={permalink}

Parameters:

- `permalink`: A permalink previously generated by this service

Response: An image representing the formula stored in the provided permalink

## Usage

Simply send a GET request to the relevant endpoint with your desired parameters.

For example, to render an image of the formula "a^2 + b^2 = c^2", first URL-encode the formula (resulting in "a%5E2+%2B+b%5E2+%3D+c%5E2"), then send a GET request to:

`http://your-domain-name.com/api/render?formula=a%5E2+%2B+b%5E2+%3D+c%5E2`
